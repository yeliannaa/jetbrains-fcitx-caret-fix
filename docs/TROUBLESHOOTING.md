# 排查说明

## 字体字形或粗细变化

安装器会使用 IDE 自带 JBR。若原来通过系统 OpenJDK 启动，IDE 的默认字体选择可能改变：在已调查的 PyCharm 2021.1.3 中，JetBrains JVM 的默认编辑字体是 JetBrains Mono；系统 JVM 下可用的默认字体可能是 DejaVu Sans Mono。

即使 `options/editor.xml` 没变，只记录了字号而没有明确字体家族，也会看到变化。先在 Settings → Editor → Font 明确选择安装前的字体与字号；原来使用 DejaVu Sans Mono 的设备可选回该字体。不要把所有用户的字体强制改成同一个值，也不要通过切回不匹配的 JDK 保留此补丁。

若本来就明确设置了字体，比较实际运行 JBR、字体是否安装、字体回退、抗锯齿和显示缩放。字体家族相同也不保证不同运行时的渲染逐像素一致。安装器不会写入字体配置。

## 显示大小变化或多屏偏移

当前启动参数包含 `-Dsun.java2d.uiScale.enabled=false`，因为已验证的补丁按 1:1 AWT 坐标工作。原设备本来就使用此设置，其他设备可能看到大小变化。保留原设置的截图/记录，再判断是否接受这个限制。删除该参数不能自动获得 HiDPI 支持；需要先验证坐标换算，见适配文档。

## 候选框仍停在左下角

1. 保存工作并完全退出 IDE 后重启，确认不是连接到旧进程。
2. Help → About 查看实际 JBR，确认启动入口确实经过已修补的 `bin/pycharm.sh`。
3. 执行 `bash diagnose.sh --ide-dir /path/to/IDE`，核对完整构建号、会话与哈希。
4. 在从终端启动的 IDE 输出中查找 `[caret-bridge] active` 或 `disabled`。只分享相关行。
5. 检查活动输入法是 Fcitx/Sogou、编辑组件能提供光标位置、AWT 坐标变换是 1:1。

`diagnose.sh` 只做静态检查，不证明 agent 已在正在运行的 IDE 中加载。它不读取编辑内容、完整环境变量、账号配置或进程参数；分享前仍应检查错误消息中可能出现的本地路径。

## 距离仍偏大、偏上或边缘出现黑框

`-50` 是验证过的搜狗插件额外高度补偿，不是通用皮肤参数。先用普通皮肤区分窗口位置和透明图像边距，再检查缩放、输入法版本及 X11 合成器。黑框可能涉及窗口透明通道/合成；本项目不替换候选渲染器，也不保证修复所有黑框问题。请勿为此随意更改全局合成器设置。

## 版本或完整性检查拒绝安装

拒绝意味着环境未匹配，或包/启动器/备份发生变化。不要用重写哈希的方式绕过。对新 JBR 必须检查 native 私有结构后重新适配。包校验失败可重新下载；自己修改源码后应重新构建、测试和打包。

若已有旧的手动补丁且工作正常，无需换成本安装器。若确需迁移，应先确认旧备份是真正的原启动脚本，再人工恢复、应用新包；安装器不会猜测原始内容。

## 卸载或更新 IDE

保留对应发布包，在启动器未经再次修改时执行卸载，再重启。若启动器被更新，自动卸载会停止；比较 `.pycharm-ime-fix/pycharm.sh.original`、`pycharm.sh.patched` 与现有脚本后人工处理。不要直接用旧备份覆盖新版 IDE 的启动器。

本安装器没有自动升级旧补丁状态的功能；相同内部状态版本下重复执行只做校验并返回。要更换补丁载荷，先用原包卸载，核对新版本兼容性，再重新安装。
